Setup Instructions
Local Network Setup (same Wi-Fi)
  1. Make sure this computer is connected to the school Wi-Fi.
  2. Start the server: run wsgi.py or double-click the desktop shortcut.
  3. On any other PC or tablet on the same network, open a browser and go to:
    {{ lan_url }}
  4. To always use the same IP, set a static IP on this machine in your router or Windows network settings.
Firewall: If other PCs cannot reach the URL, run open_firewall.bat (included in the project) to allow port {{ port }} through Windows Firewall.
Cloudflare Tunnel Setup (free, no port-forward needed)
{% if cloudflare_running %}Running{% else %}Not detected{% endif %} cloudflared process status
  1. Download cloudflared from https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
  2. Place cloudflared.exe in the project folder (already done if you see it in cloudflared/).
  3. Run the included setup_cloudflare.bat — it will open a browser to authenticate with your free Cloudflare account.
  4. Once authenticated, run install_cloudflare_service.bat to start the tunnel automatically on boot.
  5. Cloudflare will give you a public https://xxxx.trycloudflare.com URL — share that with staff.
The tunnel is free for up to 50 users. No domain name or port-forwarding required.
Cloud / VPS Deployment
  1. Get a Linux VPS — DigitalOcean, Linode, AWS EC2, or Vultr (from ~$6/month).
  2. SSH into the server and run:
    sudo apt update && sudo apt install python3 python3-pip python3-venv nginx -y
  3. Upload the project: scp -r . user@your-server:/var/www/schoolms
  4. Create venv, install requirements:
    python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
  5. Copy .env.example to .env, generate a new SECRET_KEY, fill in your database URL.
  6. Run with Gunicorn: gunicorn --config gunicorn.conf.py wsgi:app
  7. Set up Nginx as a reverse proxy using the included nginx.conf.
  8. Get a free SSL certificate: sudo certbot --nginx -d yourdomain.com
For production, switch DATABASE_URL in .env to PostgreSQL and set SECRET_KEY to a freshly generated value.
